**示例提示词：**  
```
使用德语和英语双语注释，为以下 Python 函数写注释。函数功能：读取模拟输入，计算平均值，如果超出阈值则输出报警信号。
```
然后粘贴你的代码片段，Codex 会自动生成类似：  
```python
# German: Liest den analogen Eingang und berechnet den Mittelwert.
# English: Reads analog input and calculates average.
def read_analog(channel):
    ...
```  
**注意事项：** Codex 生成的注释可能不完美，需要人工校对，尤其是专业术语（如“模拟输入”应为“analoger Eingang”）。建议结合德语技术词典验证。
