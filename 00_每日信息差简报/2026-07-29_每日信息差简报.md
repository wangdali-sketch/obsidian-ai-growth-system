## 3. 今天的 Codex 使用技巧

**技巧名称：用自然语言描述控制逻辑生成伪代码**

*使用场景：* 编写 PLC 程序前，先用 Codex（或类似 LLM 代理）将模糊需求转化为结构化伪代码，减少逻辑错误。

*示例提示词：*
```
你是一个自动化工程师。请为西门子 TIA Portal 生成一段伪代码：
- 启动按钮 I0.0 按下后，输出 Q0.0 置位。
- 当传感器 I0.1 检测到信号，延时 5 秒后 Q0.0 复位。
- 包含安全互锁：紧急停止 I0.2 为 0 时所有输出强制复位。
```

*注意事项：*
- Codex 生成的代码需经过手动验证，尤其对安全相关逻辑不能直接用于生产。
- 用英语或德语提问效果通常更好，因为训练数据中这两种语言占比较大。
- 组合使用“请用结构化文本（ST）实现”可得到更接近 IEC 61131-3 的格式。

## 6. 今天可以做的一个小任务

**任务：用 GitHub Copilot 生成一个 Python 脚本模拟西门子 PLC 数据采集**

1. 安装 VS Code 和 GitHub Copilot 扩展（若已安装可跳过）。
2. 新建一个 `plc_sim.py` 文件，顶部写注释：
   ```
   # AI-Powered PLC Data Reader Simulation
   # 模拟读取 10 个来自西门子 S7-1200 的模拟量输入（地址 AIW0-AIW18）
   ```
3. 在注释后写：`# 使用 random 模块生成 0-10V 的传感器值`
4. 观察 Copilot 的建议，接受并调整代码。
5. 最后加一行 `print("Simulation ready for edge AI inference")`。
6. 运行脚本验证。

时间：约 20 分钟。完成后你会获得一个可复用的小工具，并能体验 AI 辅助编程。
