## 3. 今天的 Codex 使用技巧

### 技巧名称：用“上下文注入”让 Codex 读懂你的电工项目

- **使用场景：** 你让 Codex 写代码时，它不知道你的项目背景。如果你是做 PLC 数据采集或者电气设备监控的，要把相关上下文直接写在提示词里。
- **示例提示词：**
  > 我是一个电气自动化专业的学生。我有一个西门子 S7-1200 PLC，通过 Modbus TCP 把电流、电压数据传到 Python 脚本里。请帮我写一个 Python 脚本，实现以下功能：1）连接 PLC 获取数据；2）当电流超过阈值时打印报警信息；3）把数据保存到 CSV 文件。请加上注释。

- **注意事项：**
  - 背景信息越具体，Codex 给出的代码越靠谱。
  - 一定要告诉 Codex 你的数据格式（比如寄存器地址、数据类型），否则它会瞎猜。
  - 不要直接用生成代码上生产线，先拿模拟数据测试。

## 4. 今天的英文资料阅读

### 英文原文选段（来自 Python 官方文档）：

> “In the following examples, input and output are distinguished by the presence or absence of prompts (>>> and …): to repeat the example, you must type everything after the prompt, when the prompt appears; lines that do not begin with a prompt are output from the interpreter.”

### 中文解释：
这段话来自 Python 官方教程的开头。它解释说：在文档的示例中，输入和输出是靠提示符区分的——`>>>` 和 `...` 前面是你需要在 Python 交互环境里输入的内容；没有提示符的行是程序输出的结果。你要想自己尝试示例，只需要输入提示符后面的内容就行。

### 关键词：
- **prompt** - 提示符（就是 `>>>`）
- **input** - 输入
- **output** - 输出
- **interpreter** - 解释器（运行 Python 的程序）
- **distinguish** - 区分

### 我应该怎么读懂它：
1. 先找到 Python 官方文档（链接在下面），打开「An Informal Introduction to Python」这一页。
2. 这段话是第一段，不用背，重点是理解“看到 `>>>` 就是要你输入代码”这个交互逻辑。
3. 读第二遍的时候，试着在你的电脑上打开 Python 交互环境（终端输 `python3`），把示例敲一遍。
4. 以后读英文技术文档遇到不认识的词，先看上下文猜，再查词典，不要每个词都查。

**来源：** [Python Documentation](https://docs.python.org/3/tutorial/introduction.html)
